Console-Grade Architecture

A browser tab can't do this. A native client delivers console perfection.

PokéBonk Deck loads the real game from pokebonk.com — same servers, accounts, and leaderboards — but provides the dedicated hardware shell the browser lacks.

Input Architecture

Real Gamepad & Steam Input

Chromium's Gamepad API is exposed directly to the game. Steam Deck's virtual controller is mapped automatically to the xlinux branch, enabling Xbox/PS glyphs, stick calibration, and tactile rumble without touch remapping.

Dual Updating

Autonomous Game Updates

The client polls version.json out-of-process every 5 minutes. Whenever Charcher deploys a new build, the webview reloads with the fresh bundle instantly. Shell updates patch via AppImage delta.

Storage Isolation

Persistent Guest & Cloud Saves

The shell isolates user data inside a persistent profile partition. Your guest progress, device token, and localStorage remain intact between boots, and official cloud logins stay authenticated.

Display

Zero Distraction Kiosk Mode

Launches directly into clean fullscreen at the Deck's native 1280×800 resolution. No navigation bars, no URL banners, and no touch popups. Just the game running with GameMode APU prioritization.

Distribution

Modern FUSE3-Free AppImage

Built using electron-builder's static 1.0.3 runtime. Requires zero legacy FUSE2 libraries, doesn't disable unprivileged user namespaces, and works seamlessly out of the box on SteamOS 3.5+.

Integrity

Zero Bundled Assets

No Nintendo or Pokémon assets are repackaged, ripped, or redistributed. The client connects cleanly to the live public site, respecting the original creator and copyright boundaries.

Installation Walkthrough

Everything needed to get up and running.

Follow our comprehensive step-by-step guide. The automated installer configures Steam library shortcuts, controller templates, and resolution flags automatically.

01

Switch to Desktop Mode

On your Steam Deck, press the physical STEAM button, navigate to Power, and select Switch to Desktop (or hold the power button for 2 seconds and select Switch to Desktop).

02

Open Konsole (Terminal)

Click the Application Launcher menu in the bottom-left corner of the taskbar, open System, and launch Konsole.

03

Paste & Run the One-Line Installer

Paste the following command into Konsole and press Enter. The installer executes fully in user space without requiring root or password:

curl -fsSL https://github.com/NaustudentX18/pokebonk-deck/releases/latest/download/install.sh | bash
1. Cryptographic Verification Validates the AppImage against official SHA-512 release digests before installation.
2. Steam Library Registration Appends the non-Steam shortcut directly to Steam's shortcuts.vdf with custom appid.
3. Controller Auto-Binding Pins configset_controller_neptune.vdf to prevent trackpad "lizard mode".
4. GameMode Optimization Creates an executable launcher wrapper applying CPU/GPU frequency governors.
04

Return to Gaming Mode & Launch

Double-click the Return to Gaming Mode shortcut on your desktop. Once back in Steam's handheld UI:

1. Open Library → select the Non-Steam tab.

2. Select PokéBonk Deck and click Play.

⚠️ Important Controller Note: When the title screen appears, press ANY button on the Deck controls (A, B, or D-pad). Chromium initializes Gamepad API state only after user interaction.

01

Download the AppImage

In Desktop Mode, download PokebonkDeck-1.1.0-x86_64.AppImage directly from GitHub Releases:

mkdir -p ~/.local/share/pokebonk-deck
cd ~/.local/share/pokebonk-deck
curl -fLO https://github.com/NaustudentX18/pokebonk-deck/releases/download/v1.1.0/PokebonkDeck-1.1.0-x86_64.AppImage
chmod +x PokebonkDeck-1.1.0-x86_64.AppImage
02

Add to Steam Client

Open the Steam Desktop client → Click Games in the top menu → Add a Non-Steam Game to My Library… → Click Browse and select ~/.local/share/pokebonk-deck/PokebonkDeck-1.1.0-x86_64.AppImage.

03

Configure Launch Options & Controller

Right-click the newly added shortcut in your Steam library → Properties:

• Launch Options: Set to gamemoderun %command%

• Controller: Under Controller settings, ensure the layout is set to Gamepad (not Desktop Layout).

Standard Desktop Linux Usage

PokéBonk Deck runs on any modern x86_64 Linux distribution (Arch, Ubuntu, Fedora, Pop!_OS, Nobara, Debian):

# Download and make executable
curl -fLO https://github.com/NaustudentX18/pokebonk-deck/releases/download/v1.1.0/PokebonkDeck-1.1.0-x86_64.AppImage

Hotplug external controllers (Xbox Series, DualSense, 8BitDo) are recognized out of the box via standard W3C Gamepad API.

Hardware Verification & Self-Test

🗑️

Clean Uninstallation

If you ever want to completely remove PokéBonk Deck, run this single clean-up command in Konsole:

rm -rf ~/.local/share/pokebonk-deck ~/.local/share/applications/gg.pokebonk.deck.desktop ~/.config/pokebonk-deck

Then right-click the shortcut in Steam and select Manage → Remove non-Steam game from your library.

Survivor Strategy

Pro tips for Steam Deck dominance.

Maximize your run efficiency and battery lifespan on handheld hardware.

Hardware Tuning

Keep on Internal SSD

The AppImage self-updater performs an atomic rename() in place. FAT32/exFAT MicroSD cards do not support atomic cross-inode renames. Keep the client on the internal NVMe drive (~/.local/share/pokebonk-deck/) for effortless in-place upgrades.

Controls

Calibrate Right Stick Camera

Run PokéBonk's built-in stick direction wizard on your very first boot. The game stores your calibrated analog thresholds in localStorage under pb-rstick, ensuring 360-degree free aiming forever.

Meta Strategy

Passive Synergy Over Sprites

Bulbasaur's passive heals 1% per grass tick, making it nearly invincible in dense swarm waves. Charmander deals +80% increased damage under 40% health. Build around passives rather than aesthetic favorites.

Frequently Asked Questions

Everything you need to know.

Does PokéBonk Deck support offline play?

No. PokéBonk is architected as an online survivor game with rankings, character unlocks, and sessions anchored to api.pokebonk.com. This client connects directly to the official server infrastructure without modifying network payloads.

Will my browser account and saves carry over?

Yes! Because the client shell operates with the official https://pokebonk.com web origin, you can log in with your existing account credentials. All cloud progress, Pokédex completions, and high scores synchronize immediately.

Why didn't my controller respond immediately upon launch?

This is a deliberate security feature of Chromium's W3C Gamepad API specification: browsers ignore gamepads until the user physically interacts with a button on the pad. Simply press A or the D-pad once on the title screen to wake the controller.

How do game and client updates work?

PokéBonk Deck features dual-channel updating: (1) The client checks version.json out-of-process every 5 minutes and hot-reloads the webview whenever a new game patch drops upstream. (2) The native AppImage shell uses electron-updater to automatically download shell bugfixes from GitHub.

Is this legal and safe to use?

Yes. PokéBonk Deck is a 100% free, open-source community client that redistributes zero copyrighted artwork, music, or game binaries. It merely provides an ergonomic native handheld window for the public website created by Charcher.
